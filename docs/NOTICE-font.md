# Eingebettete Schrift

`engine/src/core/FontData.h` enthaelt ein gerastertes Atlas der Schrift **DejaVu Sans Mono** (basiert auf Bitstream Vera, Lizenz: frei nutzbar, veraenderbar und einbettbar, Name der Schrift darf bei veraenderten Versionen nicht verwendet werden; Text: https://dejavu-fonts.github.io/License.html). Erzeugt mit `tools/gen_font.py`.
